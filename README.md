# WallGTK

WallGTK — это GTK-приложение на Go для управления обоями рабочего стола (wallpaper manager).
Приложение предоставляет графический интерфейс для выбора, просмотра и установки изображений в качестве обоев.

---

## Возможности

* Просмотр изображений в каталоге
* Установка обоев рабочего стола
* Масштабирование изображений
* Навигация по списку обоев
* Хранение настроек пользователя
* Конфигурация через файл `config.go`

---

## Требования

Перед установкой убедитесь, что в системе установлены:

### 1. Go

Минимальная версия:

```
Go 1.21+
```

Проверить:

```
go version
```

Документация Go: https://go.dev/doc/install

---

### 2. GTK4

WallGTK использует GTK4 через библиотеку gotk4.

#### Arch Linux

```
sudo pacman -S gtk4
```

#### Ubuntu / Debian

```
sudo apt install libgtk-4-dev
```

Документация GTK: https://docs.gtk.org/

## Установка

### Клонирование репозитория

```
git clone https://github.com/slnthndr/wallgtk.git
cd wallgtk
```

Документация Git: https://git-scm.com/docs/git-clone

---

### Установка зависимостей Go

```
go mod download
```

---

### Сборка

```
go build -o wallgtk
```

После сборки появится бинарный файл:

```
./wallgtk
```

---

### Быстрый запуск без сборки

Можно запустить напрямую:

```
go run .
```

---

## Конфигурация

Настройки приложения находятся в файле:

```
config.go
```

Основные параметры, которые можно изменить:

### 1. Директория с обоями

```
WallpapersDir string
```

Путь к каталогу с изображениями.

Пример:

```
~/Pictures/Wallpapers
```

---

### 2. Режим масштабирования

```
FitMode string
```

Возможные значения:

* `fill` — заполнить экран
* `fit` — вписать изображение
* `stretch` — растянуть
* `center` — по центру

---

### 3. Размер превью

```
ThumbnailSize int
```

Размер миниатюр в пикселях.

---

### 4. Интервал автосмены обоев

```
ChangeInterval int
```

Интервал в секундах.

Если `0` — автосмена отключена.

---

### 5. Тема интерфейса

```
Theme string
```

Возможные значения:

* `dark`
* `light`

---

### 6. Поведение при запуске

```
StartFullscreen bool
```

Запускать приложение сразу в полноэкранном режиме.

## Структура проекта

* `main.go` — точка входа
* `app.go` — логика GTK приложения
* `config.go` — конфигурация
* `storage.go` — работа с данными
* `tile.go` — отображение обоев
* `zoom.go` — масштабирование
* `api.go` — системные вызовы
* `types.go` — структуры данных
